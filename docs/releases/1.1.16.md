# Core 1.1.16

- Основа — опубликованный официальный Xray v26.10.31; custom transport ABI и patched uTLS/olcRTC сохранены.
- Обновлены стабильные зависимости: `golang.org/x/net v0.62.0`, gRPC `v1.85.0`; provenance сверяется с `go.mod` при проверке версии native binary.
- Самостоятельный редактор обновлён до Node.js 26.13 LTS, React 19, Mantine 9 и Vite 8. Monaco использует проверенный DOMPurify.
- Для default-режима панели добавлена отдельная WASM/schema-сборка из закреплённого pristine upstream; custom WASM и схема собираются из Core 1.1.16. Browser-валидатор не проверяет native network-доступность.

Node 1.1.25 поставляет custom и stock binaries отдельно. Default не поддерживает расширения Remnacust: смена режима не удаляет журналы квот и не отключает проверки политик. Обновление панели не обновляет удалённую ноду; смена процесса может прервать соединения. Исходники и заметки о выпуске не подтверждают публикацию бинарников.

- Based on published official Xray v26.10.31; custom transport ABI and patched uTLS/olcRTC are retained.
- Updates stable dependencies to `golang.org/x/net v0.62.0` and gRPC `v1.85.0`; the native version check verifies dependency provenance against `go.mod`.
- Updates the standalone editor to Node.js 26.13 LTS, React 19, Mantine 9 and Vite 8. Monaco uses verified DOMPurify.
- Adds a separate pinned pristine upstream WASM/schema build for default mode; custom WASM/schema use Core 1.1.16. Browser validation does not verify native network reachability.

Node 1.1.25 ships custom and stock binaries separately. Default does not support Remnacust extensions: changing mode retains quota journals and policy guards. Updating the panel does not update remote nodes; replacing the process can interrupt connections. Source and release notes do not prove binaries have been published.
