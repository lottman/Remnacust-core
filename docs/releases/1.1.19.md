# Remnacust Core 1.1.19

Сборка на Go 1.27.4 закрывает GO-2026-6859 в стандартной библиотеке net/http. Основа Xray v26.11.9 и конфигурационный формат сохранены. Серверное ядро обновляется отдельно от панели; проверьте версию фактически работающего процесса. Обновление не заменяет обновление ядра Linux.

## English

Built with Go 1.27.4 to address GO-2026-6859 in net/http. Xray v26.11.9 and the configuration format remain the baseline. Update the server core separately from the panel and verify the running process version. This does not replace Linux kernel updates.
