# Remnacust Core 1.1.18

REALITY-клиент передаёт в зашифрованном handshake версию совместимости официальной основы Xray 26.11.9 вместо номера продукта Remnacust 1.1.x. Номер бинарника остаётся 1.1.18. Это исправляет отказ штатного сервера с minClientVer 26.3.27.

Заданные minClientVer/maxClientVer и проверки ключа, shortId и времени не ослабляются. Автоматическая политика допуска старых клиентов на сервере Remnacust сохранена для совместимости; явные границы версии по-прежнему применяются. Ограничение версии upstream связано с TLS-отпечатками, не заменяет авторизацию и не доказывает отсутствие уязвимостей клиента. Используйте актуальные приложения.

Регрессионный тест выполняет настоящий loopback REALITY/TLS handshake и передачу байта. Дополнительно проверяет отказ при слишком высокой минимальной версии, слишком низкой максимальной версии, неверном ключе и shortId. Внешняя сеть и production-ноды не используются.

## English

REALITY clients now advertise the compatibility version of the pinned Xray baseline (26.11.9), independently of the Remnacust product version (1.1.18). Explicit minClientVer/maxClientVer and authentication checks remain enforced. Existing server acceptance policy is unchanged. The upstream version policy addresses TLS fingerprint compatibility; version claims are not an authorization or security attestation. Native loopback regressions cover successful encrypted traffic and rejected version bounds, keys and short IDs.
