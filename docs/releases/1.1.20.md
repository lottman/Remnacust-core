# Remnacust Core 1.1.20

Исправлено удержание сессий Xera после отклонённых загрузок: слоты и таймеры освобождаются без удаления сессии, используемой параллельным корректным запросом. HTTP/3 применяет настроенный предел заголовков. Автоматический Firefox User-Agent согласует `rv` с версией ClientHello, сохраняя явные пользовательские значения.

Частичный HTTP/2-профиль поддерживает Chrome 155 на основании сравнения SETTINGS, окна и псевдозаголовков с официальным Chrome for Testing 155.0.8059.84. Проверка сертификатов и REALITY сохраняется. Формат Xera и VLESS credentials не меняются; прежние клиенты не обязаны менять конфигурацию.

[Настройка допуска и пределы защиты](../XERA-HTTP.md): обычный padding не является секретом, общий маркер профиля не обеспечивает защиту от повторов после раскрытия, а согласование отдельных HTTP/2-полей не доказывает неотличимость от браузера или устойчивость к неизвестному ИИ-классификатору. Основа — официальный Xray v26.11.9, Go 1.27.4.

## English

Rejected Xera uploads release new session slots and timers without deleting a session used by another valid request. HTTP/3 enforces the configured header limit. Automatically generated Firefox User-Agent revisions match the selected ClientHello version while explicit values are preserved.

The partial HTTP/2 profile supports Chrome 155 after comparing SETTINGS, window and pseudoheader order with official Chrome for Testing 155.0.8059.84. Certificate and REALITY verification remain enabled. Xera framing and VLESS credentials are unchanged; existing clients do not require configuration changes.

[Admission and protection limits](../XERA-HTTP.md): ordinary padding is not a secret, a disclosed static profile marker can be replayed, and matching selected HTTP/2 fields does not establish browser indistinguishability or resistance to an unknown AI classifier. Based on official Xray v26.11.9 and Go 1.27.4.
