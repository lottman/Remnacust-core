# Remnacust Core 1.1.12

Основа: опубликованный стабильный [Xray v26.10.31](https://github.com/XTLS/Xray-core/releases/tag/v26.10.31), `a4a3dff5b20c2faae567b742c172c7b95e75c083`. Коммиты после этого тега не используются.

Включены отключение MPTCP по умолчанию, ограничения загрузки геоданных и потоковый gzip, исправления XHTTP/HTTP/DNS/QUIC и CLI балансеров. Явное включение MPTCP в sockopt сохраняется и требует безопасного ядра ОС; обновление приложения не заменяет обновление Linux.

Сохранены XERA, политики хостов и устройств, динамические квоты и безопасное применение конфигураций. Для совместимости со старыми XDRIVE-серверами исходящие Google Drive-сессии используют прежний сегментный формат. Входящие сессии распознают оба формата. S3 используется только при явной настройке.

Сборка использует Go 1.27.3. Браузерный WASM-валидатор и схемы генерируются из того же дерева исходников. Нативный тест GeoIP проверяет DNS-разрешение домена перед общим маршрутом и сохранение приоритета ручных правил, используя только локальные HTTP и SOCKS-слушатели.
