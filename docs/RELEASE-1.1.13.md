# Core 1.1.13

Один ключ устройства теперь сохраняет общий предел скорости и долю очереди при переключении между серверами автовыбора. Идентификаторы маршрутов по-прежнему разделяют доступ и учёт; общий лимит пользователя действует на все его устройства.

Политики получателя применяются и на входе, который допускает обычные прямые подключения без ограничений хоста. Создание автовыбора не отзывает такие прямые ключи. Неизвестные ключи маршрутов и ключи другого входа отклоняются.

Возможность `remnacust-routed-device-speed-v1` требует Node 1.1.22 и панели 1.1.7.93. Обновите подписку клиента после обновления нод. Основой остаётся опубликованный Xray v26.10.31; настройки MPTCP не меняются.
